Scene 1 • 00:00 - 01:45 Vision & Problem

The Problem with Naive RAG & Why Citations Break

Standard conversational LLMs fail in enterprise research because they hallucinate facts and invent fictional citations. Naive vector search misses exact keywords, models fabricate page numbers, and prompt-injections compromise system boundaries. KnowledgeVault AI solves this through verifiable hybrid retrieval and strict citation validation.

Scene 2 • 01:45 - 03:30 Architecture

Full-Stack Decoupled Architecture

FastAPI handles async REST requests with Pydantic v2 schemas. Ingestion runs via PyMuPDF with page-level metadata. Storage uses SQLite in WAL mode for lightweight local zero-config operation alongside Dockerized PostgreSQL and Qdrant for enterprise deployment. React 18 + Vite provides a responsive, accessible dashboard.

Scene 3 • 03:30 - 05:30 Ingestion

Document Ingestion Pipeline & Page Tracking

Every uploaded file undergoes SHA-256 fingerprinting to prevent redundant re-indexing. PyMuPDF extracts text page-by-page, preserving physical page numbers. Chunker splits passages into ~700 tokens with 100-token sliding overlap at paragraph boundaries. Dense embeddings are generated using sentence-transformers/all-MiniLM-L6-v2.

Scene 4 • 05:30 - 07:30 Retrieval Math

Hybrid Search & Reciprocal Rank Fusion (RRF)

Dense vector search excels at conceptual matching but struggles with exact acronyms (e.g. AUC-ROC, XGBoost). BM25 Okapi indexes exact lexical frequencies. Reciprocal Rank Fusion blends both lists using formula RRF = Σ 1/(k + rank) with k=60, doubling Recall@5 from 50.0% to 100.0%.

Scene 5 • 07:30 - 09:30 Citations

Verifiable Citation Validator & Anti-Hallucination

The LLM returns structured citation tokens [cite:doc_id:chunk_id]. The backend CitationValidator intercepts every reference, checks that the cited chunk exists in the retrieved context, strips hallucinated IDs, and attaches the exact physical page number and snippet text for interactive frontend popovers.

Scene 6 • 09:30 - 11:15 Security

Prompt Injection Defense & Boundary Isolation

User-uploaded documents can contain adversarial prompts. KnowledgeVault AI encloses all document excerpts within strict XML boundaries <context>...</context> and instructs the model to treat document content purely as passive untrusted evidence, refusing any internal commands embedded in files.

Scene 7 • 11:15 - 13:00 Evaluation

Empirical Benchmark Suite: Dense vs Hybrid

Measured against a 30-question benchmark dataset: Dense Baseline scored Recall@5 = 50.0% and MRR = 0.4333. Hybrid RRF reached Recall@5 = 100.0% and MRR = 0.8111. Cross-Encoder reranking further boosted MRR to 0.8333 with Faithfulness at 91.86%.
